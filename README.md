# scikit-learn Cookbook, Third Edition

This repository contains Jupyter notebooks for the individual enrichment assignment for Machine Learning classes. The notebooks follow *scikit-learn Cookbook, Third Edition* by John Sukup (O'Reilly) and combine practical scikit-learn code examples with theoretical explanations.

## Chapters

| Chapter | Topic | Summary |
|---|---|---|
| 1 | Common Conventions and API Elements of scikit-learn | Introduces the estimator API, fitting and prediction, transformers, pipelines, and model selection conventions. |
| 2 | Pre-Model Workflow and Data Preprocessing | Covers missing values, feature scaling, categorical encoding, feature engineering, and preprocessing pipelines. |
| 3 | Dimensionality Reduction Techniques | Explores PCA, LDA, t-SNE, and feature-selection approaches for reducing or selecting features. |
| 4 | Building Models with Distance Metrics and Nearest Neighbors | Demonstrates nearest-neighbor classification and regression, distance metrics, hyperparameter tuning, and evaluation. |
| 5 | Linear Models and Regularization | Covers ordinary least squares, Ridge, Lasso, Elastic Net, regularization strength, cross-validation, and regression metrics. |
| 6 | Advanced Logistic Regression and Extensions | Reserved for the Chapter 6 notebook. |
| 7 | Support Vector Machines and Kernel Methods | Reserved for the Chapter 7 notebook. |
| 8 | Tree-Based Algorithms and Ensemble Methods | Reserved for the Chapter 8 notebook. |

## How to use

1. Open a notebook in GitHub to preview its explanations and code.
2. To execute a notebook, download it or open it in [Google Colab](https://colab.research.google.com/).
3. Run the cells from top to bottom. Some notebooks use synthetic datasets so the examples can run without external data downloads.
