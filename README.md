# scikit-learn Cookbook, Third Edition

This repository contains chapter-organized Jupyter notebooks for the Machine Learning enrichment assignment. It follows *scikit-learn Cookbook, Third Edition* by John Sukup (O'Reilly), combining practical examples with theoretical explanations and exercises.

## Chapters

| Chapter | Topic | Summary |
|---|---|---|
| 1 | Common Conventions and API Elements of scikit-learn | Estimator API, transformers, pipelines, model selection. |
| 2 | Pre-Model Workflow and Data Preprocessing | Missing values, scaling, encoding, feature engineering. |
| 3 | Dimensionality Reduction Techniques | PCA, LDA, t-SNE, feature selection. |
| 4 | Distance Metrics and Nearest Neighbors | KNN, distance metrics, tuning, evaluation. |
| 5 | Linear Models and Regularization | OLS, Ridge, Lasso, Elastic Net, CV, regression metrics. |
| 6 | Advanced Logistic Regression and Extensions | Binary/multiclass classification, regularization, thresholds, metrics. |
| 7 | Support Vector Machines and Kernel Methods | Linear, polynomial, RBF kernels and tuning. |
| 8 | Tree-Based Algorithms and Ensemble Methods | Decision trees, random forests, boosting, stacking. |
| 9 | Text Processing and Multiclass Classification | BoW, TF-IDF, n-grams, text classifiers. |
| 10 | Clustering Techniques | K-means, agglomerative clustering, DBSCAN. |
| 11 | Novelty and Outlier Detection | Isolation Forest, LOF, One-Class SVM. |
| 12 | Cross-Validation and Model Evaluation Techniques | K-fold, stratified CV, LOOCV, nested CV, metrics, learning curves. |
| 13 | Deploying scikit-learn Models in Production | Persistence, inference, monitoring, metadata, lifecycle practices. |

## How to use
1. Open notebooks in GitHub to preview Markdown, code, and saved outputs.
2. To run a notebook, download it or open it in [Google Colab](https://colab.research.google.com/).
3. Run cells from top to bottom. Examples use built-in or synthetic data.
4. Chapter 13 creates a local `model_artifacts` directory when executed.
