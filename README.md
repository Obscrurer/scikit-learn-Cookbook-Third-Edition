# scikit-learn Cookbook, Third Edition

This repository contains chapter-organized Jupyter notebooks for the individual Machine Learning enrichment assignment. It follows *scikit-learn Cookbook, Third Edition* by John Sukup (O'Reilly), combining practical scikit-learn examples with theoretical explanations and exercises.

## Chapters

| Chapter | Topic | Summary |
|---|---|---|
| 1 | Common Conventions and API Elements of scikit-learn | Estimator API, fitting and prediction, transformers, pipelines, and model selection conventions. |
| 2 | Pre-Model Workflow and Data Preprocessing | Missing values, feature scaling, categorical encoding, feature engineering, and preprocessing pipelines. |
| 3 | Dimensionality Reduction Techniques | PCA, LDA, t-SNE, and feature-selection approaches. |
| 4 | Building Models with Distance Metrics and Nearest Neighbors | Nearest-neighbor classification and regression, distance metrics, hyperparameter tuning, and evaluation. |
| 5 | Linear Models and Regularization | Ordinary least squares, Ridge, Lasso, Elastic Net, regularization strength, cross-validation, and regression metrics. |
| 6 | Advanced Logistic Regression and Extensions | Binary and multiclass logistic regression, regularization, class weighting, decision thresholds, and classification metrics. |
| 7 | Support Vector Machines and Kernel Methods | Linear, polynomial, and RBF kernels, decision boundaries, hyperparameter tuning, and high-dimensional classification. |
| 8 | Tree-Based Algorithms and Ensemble Methods | Decision trees, random forests, gradient boosting, hyperparameter tuning, and stacking. |

## How to use

1. Open a notebook in GitHub to preview its Markdown explanations, code, and saved outputs.
2. To execute a notebook, download it or open it in [Google Colab](https://colab.research.google.com/).
3. Run the cells from top to bottom. The notebooks use built-in or synthetic datasets, so they do not require external dataset downloads.
